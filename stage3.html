    E Who fills each field?

    For each field of the base chosen above: who fills its values day to day. It is built from the latest saved version of each automation and form recorded here, and from the field's own type. A person typing into a field cannot be read from those records, so it is only ever shown as possible. A field carries the Fusion-driven marker if, and only if, a recorded automation sets it (a field only read or tested in a condition does not); Fusion is the only automation engine in the target. The outcome says what still needs a decision: a formula, lookup or rollup is recomputed in the target or parked; a field only an automation fills becomes Fusion-owned, goes stale, or is also edited by people. The page shows field and automation names only, no record values.

    Check the descriptions pulled from Workfront

    Compares the matrix with the field descriptions as they stand in Workfront Core and Workfront Planning, in both directions, so the two cannot drift apart: every field a recorded automation sets must carry the Fusion-driven marker, and every marked field must trace back to a recorded automation. Upload a .csv (or .json) with the columns system (core or planning), description, and either field_id (the Airtable field ID) or workfront_id (matched through the load ID map). Only the systems in the file are checked. Nothing is stored and no description is shown back: the page lists field names, IDs and one sentence per finding. A field missing from the file is counted as not pulled, not as a failure.
