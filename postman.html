Postman tests for the Workfront Planning API

Five short tests to run yourself in Postman, in a DEV Workspace only, with throwaway records. Each one settles a design decision the migration cannot settle from the documentation alone. This page only shows you what to send and how to read the answer: it never calls Workfront and never sees a token. You add your own authorization in Postman; the saved v2 reference does not say how Planning authenticates, so confirm that in Adobe Developer Console or the Workfront documentation.

Requests go to https://{customer-domain}/maestro/api plus the path shown. The paths, property names and limits come from the saved Planning API v2 reference; where the reference is silent the test is how you find out.

    Download the Postman collection (.json) Every step and cleanup request, with variables, ready to import (Import, then choose the file). It holds no authorization.
