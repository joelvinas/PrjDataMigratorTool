Extract to CSV

Turns one saved Airtable table extract (the .json file the extract step writes into data_extract) into a CSV you can open in Excel and check against Airtable. This page needs no database and no token. The file is read in memory, converted and handed back; nothing is stored, and the values are not shown on this page.

What the CSV holds. The first rows give the extract's facts (format, base_id, table_id, table_name, captured_at, record_count, field_count), then two blank rows. Next come a field_id row and a data_type row, then the heading row (record_id, createdTime, then one field name per column), then one row per record. A list (linked records, multiple selects, attachments) stays in its one cell as JSON text, and long text keeps its line breaks inside its cell. Commas, quotes and slashes in a value are handled. A true or false is written true or false, and an empty value is an empty cell.
