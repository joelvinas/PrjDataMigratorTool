🚨 Emergency mode

Pushes one table into the dev Workspace of config.json in one click. Names are sent exactly as Airtable has them. Each field is tried as its real Planning type; when Planning refuses it, it is created as a text field named PRE- + the field name (long text when the longest value is over 255 characters, at most 20 long-text fields per record type). Arrays are stored as raw JSON text in a PRE- field. Links and attachments are skipped for later. A failing field or record never stops the run. Running it again reuses the record type and fields and sends only the records not yet loaded.
