🚨 Git-R-Done

Pushes one table into the Workspace of the Planning stage you pick (the stages are the blocks of workfront.planning in config.json: dev, test, prod) in one click. Sending to the production stage asks you to type CREATE IN PRODUCTION (DELETE RECORDS IN PRODUCTION for a reset) first. Names are sent exactly as Airtable has them. Each field is tried as its real Planning type; when Planning refuses it, it is created as a text field named PRE- + the field name (long text when the longest value is over 255 characters, at most 20 long-text fields per record type). A multiple select is created as a real multi-select field (its options must all be different first); other arrays are stored as raw JSON text in a PRE- field. Attachments are skipped for later. Links are set by a second visit (the Links card below): Go skips every link field, and holds back every field whose value comes through a link (a lookup, a rollup, a count, or a formula that reads a link). Those are never loaded as text; once the tables they point to are loaded, the links pass creates the reference fields and sets the links, and a person creates the lookups in Planning by hand (Planning cannot create them through its API). A calculated (formula) field that reads no link is rebuilt as a real Planning formula after the other fields; the Calculated fields card shows beforehand which ones can be built, which are held back and which will be stored as PRE- text. A failing field or record never stops the run. Running it again reuses the record type and fields and sends only the records not yet loaded.

The Table picker shows the order to take the tables in. Green: done, nothing more to do. Yellow: run, but another pass is needed (it moves to just after the table its links wait for). No colour: not run yet.

Reset table starts the chosen table over so you can try again: it tries to delete the table's record type in Workfront (Adobe deletes its fields and records with it) and, only when Workfront confirms it is gone, forgets the IDs this tool holds for the table. If Workfront refuses, you are told why and nothing is forgotten unless you choose to. Names, types and every decision are kept. It works for a table loaded here or on Load a table, and is not held back by the Load a table steps.

    Run this after the table has been loaded with Go and the tables its links point to have been loaded too.
