🚨 Git-R-Done

Pushes one table into the dev Workspace of config.json in one click. Names are sent exactly as Airtable has them. Each field is tried as its real Planning type; when Planning refuses it, it is created as a text field named PRE- + the field name (long text when the longest value is over 255 characters, at most 20 long-text fields per record type). A multiple select is created as a real multi-select field (its options must all be different first); other arrays are stored as raw JSON text in a PRE- field. Links and attachments are skipped for later. A calculated (formula) field is rebuilt as a real Planning formula after the other fields; the Calculated fields card shows beforehand which ones can be built, which wait for another table (and which table to run first) and which will be stored as PRE- text. A failing field or record never stops the run. Running it again reuses the record type and fields and sends only the records not yet loaded.

Reset table starts the chosen table over so you can try again: it tries to delete the table's record type in Workfront (Adobe deletes its fields and records with it) and, only when Workfront confirms it is gone, forgets the IDs this tool holds for the table. If Workfront refuses, you are told why and nothing is forgotten unless you choose to. Names, types and every decision are kept. It works for a table loaded here or on Load a table, and is not held back by the Load a table steps.
